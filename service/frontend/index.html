API usage 📡

This page is a thin client over the REST API. The same calls from the command line:

curl -X POST "http://localhost:8000/extract_keywords" \
  -F "file=@lines.txt"

# optional: accrete into an existing ATRIUM Document record
curl -X POST "http://localhost:8000/extract_keywords" \
  -F "file=@lines.txt" -F "document_json=@CTX000000001.atrium.json"

curl -X POST "http://localhost:8000/extract_keywords_text" \
  -H "Content-Type: application/json" \
  -d '{"text": "Výzkum odhalil základy kostela."}'

The backend and model are server-side settings (LLM_BACKEND); GET /info reports which ones the running server chose.
